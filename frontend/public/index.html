MyHealth Access

Patient

Wähle eine Aktion, um die zugehörigen Daten anzuzeigen.

Patient hinzufügen

Legt einen neuen Login (Rolle Patient) und dessen verknüpften FHIR-Datensatz an. Der Patient kann sich anschließend anmelden und seine Freigaben selbst verwalten.

Arzt hinzufügen

Legt einen neuen Login mit Rolle Arzt (und Patient) samt eigenem FHIR-Datensatz an — wie dr.smith/dr.bob. Zugriff auf fremde Patienten wird von diesen zur Laufzeit freigegeben.

Klinische Daten hinzufügen

Fügt eine Diagnose, Medikation oder Allergie zu einem Patienten hinzu.

Meine Freigaben

Gib Ärzten Lesezugriff auf deine Daten frei oder sperre einzelne Einträge. Änderungen wirken sofort.

Noch keine Anfrage — wähle links eine Aktion, um Daten anzuzeigen.
